Visual Bugs
- Mods with a custom executable ending in 'DDLC.exe' i.e. 'TheOutside_DDLC.exe' would
not be shown as containing a custom executable.
- Padding for screenshots under mods has been fixed.

- MacOS Fixes
    Fallen Angle - Game Folder Mods Would Just Dump
    Their Contents Into Autorun Instead Of Game

    Exit Music Redux - Auto Nested Folder Detection Failed
    Causing none of the mod files to be properly added

    was being blocked because of the size limit (to prevent zip bombs)

    Blue Skies - Buffered Decode Size was too small, causing
    the 'scripts.rpa' file to not extract

    Google Drive Downloads On MacOS Fixed

    Fixed custom images not displaying
    Window is now rounded properly.
    Mac DMG download works correctly now, you still need to allow
        DDMM through gatekeeper though
